### 1. Spring Task 定时任务实现

**任务**：编写 Spring Task 定时任务，定期检查 learning_lesson 表中的课程是否过期，如果过期则将课程状态修改为已过期。

**完成内容**：
- 在 `ILearningLessonService` 接口中添加 `updateExpiredLessons()` 方法
- 在 `LearningLessonServiceImpl` 中实现 `updateExpiredLessons()` 方法
- 创建 `LessonExpirationTask` 定时任务类

**关键代码**：

```java
@Slf4j
@Component
@RequiredArgsConstructor
public class LessonExpirationTask {

    private final ILearningLessonService lessonService;

    @Scheduled(fixedDelay = 3600000)
    public void checkExpiredLessons() {
        log.debug("开始检查过期课程");
        try {
            lessonService.updateExpiredLessons();
            log.debug("过期课程检查完成");
        } catch (Exception e) {
            log.error("检查过期课程时发生异常", e);
        }
    }
}
```

**技术要点**：
- 使用 `@Scheduled(fixedDelay = 3600000)` 实现每小时执行一次
- 使用 `fixedDelay` 而非 `fixedRate`，避免任务重叠
- 必须捕获异常，避免任务中断
- 批量更新数据库，提高性能

### 2. jdtls 安装配置

**任务**：安装 Eclipse JDT Language Server，用于 Java 代码静态分析。

**完成内容**：
- 下载并解压 jdtls 到 `D:\tools\jdtls`
- 配置 Java 21 环境（jdtls 需要 Java 21+）
- 将 jdtls 添加到 PATH 环境变量

**配置命令**：
```powershell
# 下载 jdtls
Invoke-WebRequest -Uri "https://download.eclipse.org/jdtls/snapshots/jdt-language-server-latest.tar.gz" -OutFile "D:\tools\jdtls\jdtls.tar.gz"

# 解压
cd D:\tools\jdtls; tar -xzf jdtls.tar.gz

# 添加到 PATH
[Environment]::SetEnvironmentVariable("Path", "D:\tools\jdtls\bin;" + [Environment]::GetEnvironmentVariable("Path", "User"), "User")
```
