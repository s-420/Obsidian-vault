## 知识点摘要

### 1. Springfox → SpringDoc OpenAPI3 迁移
> **完整内容**：[[JavaProject/天机学堂/Springfox迁移OpenAPI3]]

**一句话总结**：将 springfox 停止维护的 Swagger 迁移到 springdoc-openapi3，核心是注解映射（@Api→@Tag, @ApiOperation→@Operation）和配置类重写。

**关键收获**：
- OpenAPI3 的 `@Schema` 没有 `value()` 属性，必须用 `description`
- `@Tag` 用 `name` 不是 `tags`
- springdoc 1.x 对应 Spring Boot 2.x，2.x 对应 3.x

### 2. ThreadLocal 跨微服务用户传递
> **完整内容**：[[JavaProject/天机学堂/ThreadLocal跨服务用户传递]]

**一句话总结**：通过 Feign 拦截器 + HTTP Header 实现 ThreadLocal 跨服务传递用户信息。

**关键收获**：
- `UserContext` 存储在 tj-common 模块，所有服务共享
- `UserInfoInterceptor`：HTTP Header → ThreadLocal
- `FeignRelayUserInterceptor`：ThreadLocal → HTTP Header
- 异步场景会丢失，需要用 `InheritableThreadLocal`

> **完整内容**：[[JavaProject/天机学堂/MyBatis-Plus分页查询]]
