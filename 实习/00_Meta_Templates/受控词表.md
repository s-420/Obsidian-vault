# 受控词表

> 所有笔记的 `tech_stack` / `tags` 取值**必须**以此表为准（如写 `SpringBoot`，不写 `spring boot`）。新增词汇请按"追加规范"登记。

## tech_stack 推荐枚举
| 规范写法 | 说明 |
|---------|------|
| Java | 语言 |
| SpringBoot | 框架 |
| SpringCloud | 微服务 |
| MyBatis-Plus | ORM |
| MySQL | 数据库 |
| Redis | 缓存 |
| RocketMQ | 消息队列 |
| Kafka | 消息队列 |
| Docker | 容器 |
| Git | 版本控制 |

## tags 推荐枚举
| 层级 | 规范写法 | 说明 |
|------|---------|------|
| 公司层 | 实习/飞冰科技 | 每家公司一个 |
| 类型层 | BugFix / Feature / 优化 / 调研 | 笔记类型 |
| 文档层 | DailyLog / TechDeepDive / BusinessContext / ResumeAsset | 对应四类模板 |
| 主题层 | 实习/飞冰科技/订单 | 按业务主题细化，随实习深入追加 |

## 追加规范
新增 tech_stack 或 tags 词汇时：
1. 在本表对应枚举中追加一行
2. 在下方 Changelog 登记（日期 + 新增词 + 原因）
