# Scribe 文档转换器需求文档

## 1. 背景与目标

Scribe 免费版可以录制网页操作，但 Word/PDF 导出和桌面捕捉存在套餐限制。用户可以在已经登录的浏览器中将 Scribe 页面保存为“完整网页”，并将 HTML 与资源文件夹压缩成 ZIP。

本项目的目标是把该 ZIP 在本地快速转换成图片内嵌的 Word 操作指南，便于导入飞书云文档。工具需要避免重复网页访问、浏览器自动化和不必要的渲染探测，将常规转换控制在一次命令内完成。

## 2. 目标用户与使用场景

### 核心用户

- 需要将 Scribe 操作步骤整理到飞书知识库的实习生或运营人员。
- 需要制作内部系统操作手册，但不希望购买 Scribe 导出订阅的个人用户。

### 核心场景

1. 用户在浏览器中打开完整 Scribe。
2. 用户选择“网页，全部”并将 HTML 与资源目录压缩为 ZIP。
3. 用户运行本地转换命令。
4. 工具在 `output/` 生成 Word。
5. 用户将 Word 导入飞书并做最终确认。

## 3. MVP 功能范围

### 必须做

1. **ZIP 输入**：接受一个由浏览器保存的 Scribe 完整网页 ZIP。
2. **安全解压**：拒绝绝对路径和目录穿越条目，不覆盖原始输入。
3. **HTML 自动识别**：在压缩包中定位主 HTML 和同名资源目录。
4. **步骤解析**：提取文档标题、说明、步骤序号和操作文字。
5. **截图匹配**：优先使用本地 `action-*.png`，按步骤关联图片。
6. **缺失处理**：截图缺失时保留文字步骤并明确标记，不联网补图。
7. **Word 生成**：生成图片内嵌、可独立移动的 `.docx`。
8. **统一排版**：使用固定的中文操作指南模板，包括标题、步骤标题、说明、截图和完成检查。
9. **快速校验**：验证 DOCX 可读取、步骤数、嵌入图片数、图片替代文本和输出路径。
10. **单命令入口**：提供 `convert.ps1 <zip路径>`。
11. **本地处理**：默认不联网，不需要 Scribe Token 或登录信息。

### 可以砍

1. **视觉渲染参数**：`--verify` 可在本机存在 LibreOffice 或可用 Word 渲染链路时执行逐页检查；MVP 默认关闭。
2. **多模板支持**：第一版只保留一个固定模板，后续再开放 JSON 配置。
3. **HTML 直接输入**：第一版以 ZIP 为主；资源齐全时可后续支持 HTML 路径。
4. **自动翻译**：保留源文本或使用确定性中文规则，不调用在线 AI 翻译。
5. **批量转换**：第一版一次处理一个 ZIP。

### 明确不做

1. 不读取或保存 Scribe Token、Cookie、账号和密码。
2. 不绕过 Scribe 权限或套餐限制。
3. 不自动登录 Scribe 或控制用户浏览器。
4. 不自动上传飞书、不修改飞书云文档。
5. 不修改或删除用户原始 ZIP、HTML 和截图。
6. 不凭空生成缺失截图或未经来源支持的操作步骤。

## 4. 核心用户流程

1. 用户将 Scribe 保存为完整网页并压缩为 ZIP。
2. 用户把 ZIP 放入 `input/`，或直接在命令中提供绝对路径。
3. 用户执行 `convert.ps1 "输入文件.zip"`。
4. 入口脚本检查文件存在性、扩展名和运行环境。
5. 转换器创建独立临时目录并安全解压。
6. 转换器解析主 HTML，识别标题、描述和步骤卡片。
7. 转换器建立步骤与本地图片的映射；找不到本地图片时记录缺失原因。
8. 转换器生成统一排版的 Word，并将图片嵌入 DOCX。
9. 转换器重新打开 DOCX，检查步骤数、图片数和结构完整性。
10. 转换成功后，将结果写入 `output/`，打印耗时、步骤数、图片数、缺失项和文件路径。
11. 工具清理本次临时目录；输入文件保持不变。

## 5. 输入与输出约定

### 输入

- 文件类型：`.zip`
- 内容：一个主 `.html` 文件和一个对应的资源目录。
- 图片：优先识别 `action-*.png`，兼容相对路径引用。

### 输出

- 文件类型：`.docx`
- 默认目录：`output/`
- 默认文件名：清理后的 Scribe 标题。
- 运行摘要：步骤数、成功嵌入图片数、缺失图片的步骤、总耗时。

## 6. 异常与边界

- ZIP 不存在、不是 ZIP 或无法读取：终止并给出明确错误。
- ZIP 包含路径穿越：拒绝解压并报告风险条目。
- 找不到 HTML：终止，不生成空 Word。
- 找到多个候选 HTML：按 Scribe 特征评分选择；无法唯一判断时终止并列出候选。
- 找不到步骤卡片：终止并提示该页面可能没有完整加载后再保存。
- 图片损坏：跳过图片，在对应步骤中标记损坏文件。
- 重复图片：允许多个步骤复用同一张图，但 DOCX 中的说明保持独立。
- 输出同名文件存在：默认生成带时间后缀的新文件，不静默覆盖。

## 7. 非功能要求

- 常见 10～30 步文档的快速模式目标：30 秒内完成。
- 全流程默认离线运行。
- Windows 作为首要运行环境。
- 控制台信息使用中文，错误信息可直接用于排查。
- 工具目录结构清晰，输入、输出、临时文件和源码分离。

## 8. 开发路线图

### 阶段 A：项目与需求基线

- 建立项目目录、README、AGENTS 和需求文档。
- 确认 MVP、技术栈、依赖和 Git 方案。

### 阶段 B：解析与文档生成

- 实现 ZIP 安全解压。
- 实现 Scribe HTML 解析和步骤/图片映射。
- 实现固定 Word 模板和快速结构校验。

### 阶段 C：命令入口与测试

- 提供 PowerShell 单命令入口。
- 使用脱敏夹具覆盖正常、缺图、损坏图、多 HTML 和恶意 ZIP 场景。
- 输出可核验的测试报告。

### 阶段 D：可选增强

- 增加 `--verify` 视觉渲染。
- 增加模板配置、HTML 输入和批量处理。

## 9. 本阶段验收标准

- “必须做 / 可以砍 / 明确不做”边界清晰。
- 输入、输出和缺失截图策略符合实际工作流。
- 默认快速模式不再尝试网页访问或多套渲染器。
- 后续实现能够在指定项目目录中独立运行。

## 10. 最终能实现什么

用户以后只需保存 Scribe 完整网页 ZIP 并运行一次命令，即可获得图片内嵌、结构统一、适合导入飞书的 Word 文档；常规任务不再重复网页访问、Token 探测和失败的渲染尝试，从而显著缩短处理时间并保持输出一致。
