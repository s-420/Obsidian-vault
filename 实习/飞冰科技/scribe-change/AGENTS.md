# 项目协作规则

## 项目边界

- 只处理用户明确提供的本地 Scribe HTML 或 ZIP。
- 默认不联网，不读取浏览器 Token、Cookie、密码或其他凭据。
- 输入、临时文件和输出均限制在本项目目录或用户显式指定的路径。
- 不修改原始 ZIP、HTML 和图片资源。

## 阶段门禁

- 需求、架构和实现按项目文档逐阶段验收。
- 需求变化先更新 `docs/01-需求文档.md`。
- 正式代码产出前必须确认技术栈、依赖策略、Git 初始化与基线范围。
- 不自动创建远程仓库，不自动推送。

## 验证要求

- 必须验证步骤数量、图片数量、缺失图片标记和 DOCX 可读取性。
- 不把缺失步骤或截图伪造成已存在内容。
- 正式交付模式应执行可用的视觉渲染；渲染工具不可用时必须明确报告。

## 禁止提交

- 用户输入 ZIP、HTML、截图和生成的 Word。
- Token、Cookie、账号信息及其他敏感配置。
- 临时解压目录、缓存、日志和本地虚拟环境。
