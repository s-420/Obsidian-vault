# Scribe 文档转换器使用说明

## 最快用法

1. 双击 `Scribe文档转换器.exe`。
2. 选择从 Chrome 保存并压缩好的 Scribe ZIP。
3. 点击“开始转换”。
4. Word 会生成在原 ZIP 所在目录，文件名保持一致。

## 使用前：先在 Scribe 完成这些操作

1. 使用 Chrome 登录 Scribe，并确认目标指南可以正常打开。
2. 从第一个步骤开始向下滚动，直到最后一个步骤，确保所有步骤和截图都实际显示过。
3. 如果页面较长，滚动到底后稍等几秒，让最后一批截图完成加载。
4. 按 `Ctrl+S`，保存类型必须选择“网页，全部”，不要选择“仅 HTML”。
5. 保存完成后，应得到以下两个项目：
   - 一个 `.html` 文件；
   - 一个名称基本相同、以 `_files` 结尾的资源文件夹。
6. 不要重命名、拆散或只保留其中一个。选中 HTML 和 `_files` 文件夹，将两者一起压缩成 ZIP。
7. ZIP 保存后立即运行转换器，避免 Scribe 临时图片链接过期。

> 重要：如果没有先完整滚动页面，Chrome 可能只保存当前已加载的少量截图。转换器无法从已经过期的链接恢复图片。

程序优先使用 ZIP 内的本地图片；本地缺失时，会尝试使用 HTML 中仍然有效的临时图片地址在线补图。程序不会读取 Cookie、密码或浏览器凭据。

Scribe 图片地址通常只有较短有效期，建议保存 ZIP 后立即转换。若地址已经过期，请重新打开页面并再次使用“网页，全部”保存。

## 命令行用法

```powershell
.\convert.ps1 "D:\资料\某个Scribe页面.zip"
```

也可以直接运行：

```powershell
.\Scribe文档转换器.exe "D:\资料\某个Scribe页面.zip"
```

指定输出位置：

```powershell
.\Scribe文档转换器.exe "input.zip" -o "output.docx"
```

完全离线转换：

```powershell
.\Scribe文档转换器.exe "input.zip" --offline
```

## 输出说明

- 每个步骤都会写入 Word。
- ZIP 中存在的截图会内嵌到 Word，不依赖外部链接。
- 本地缺失且在线补图失败的截图会标记为 `[本地图片缺失]`。
- 原 ZIP、HTML 和图片不会被修改。

## 常见问题

**提示“没有识别到 Scribe 操作步骤”**  
请重新使用 Chrome 的“网页，全部”保存，不要只保存 HTML。

**Word 中部分步骤没有图片**  
先检查以下事项：

1. 保存前是否从第一步滚动到了最后一步；
2. 保存类型是否为“网页，全部”；
3. HTML 和 `_files` 文件夹是否一起放进 ZIP；
4. 是否在保存 ZIP 后立即转换。

如果仍然缺图，请重新打开 Scribe 页面、完整滚动并重新保存。已经过期的截图链接无法从旧 ZIP 中恢复。

**杀毒软件首次提示未知程序**  
这是本地打包、没有数字签名的便携程序。代码完全离线运行；若公司电脑有严格策略，可使用源码版运行。
