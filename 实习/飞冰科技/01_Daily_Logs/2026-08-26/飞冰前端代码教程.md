### 二、下载 nvm

nvm(Node Version Manager)是 Node.js 的版本管理工具,主要用来在一台机器上安装、切换、管理多个 Node.js 版本。

它解决的核心问题是:不同项目依赖的 Node 版本常常不同(比如老项目要 Node 14,新项目要 Node 20),nvm 让你能在这些版本之间自由切换,而不需要反复卸载重装。常用命令大概是 nvm install 20 安装、nvm use 20 切换、nvm list 查看已装版本、nvm alias default 20 设默认版本。
